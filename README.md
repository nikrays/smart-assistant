# Smart Assistant

[Открыть демоверсию](https://nikrays.github.io/smart-assistant/)

Рабочее пространство директора сельскохозяйственного предприятия: личные задачи, ежедневный журнал, техника и обслуживание по моточасам, склад и расчёты.

Эта публичная версия работает на GitHub Pages с вымышленными данными. Изменения сохраняются только в браузере посетителя. Кнопка «Сбросить демо» восстанавливает учебные записи. Не вводите реальные документы, пароли и персональные данные.

## Попробовать

1. В личных задачах введите поручение, нажмите «Подготовить задачу», проверьте форму и сохраните. Обновите страницу: задача останется.
2. В ежедневном журнале добавьте работу, проверьте и подтвердите её, затем создайте связанный табель.
3. В разделе «Техника и ТО» запишите моточасы и посмотрите, как меняется срок обслуживания. Учебное ТО связывает работу, табель и расход материалов.
4. Откройте поиск, помощь и тур. Переключите тему или размер окна.

CSV выгружает текущие данные браузера. «Пример Excel» скачивает фиксированный учебный отчёт. Голос, внешние интеграции, настоящие аккаунты и серверные резервные копии требуют отдельного сервера и в этой версии не подключены.

## Локальная сборка

Node.js 24, npm. Проверки и сборка выполняются в Linux или WSL.

```sh
cd frontend
npm ci --ignore-scripts --no-audit --no-fund
npm run test:drafts
npm run test:numbers
npm run test:pages
npm run build:pages
npx vite preview --host 127.0.0.1
```

В репозитории опубликована браузерная демоверсия. Серверный код, PostgreSQL, рабочие документы и данные предприятия сюда не входят.

GitHub Actions проверяет, собирает и публикует `frontend/dist` при изменениях ветки `main`. Подробности: [публикация демо](docs/PAGES_DEMO.md), [дизайн-система](DESIGN.md), [лицензии зависимостей](THIRD_PARTY_NOTICES.txt).
