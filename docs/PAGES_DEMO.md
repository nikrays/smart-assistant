# Публичная демонстрация Smart Assistant

GitHub Pages размещает браузерную демонстрацию. Интерфейс совпадает с приложением, данные вымышленные. Изменения и незаконченные формы сохраняются только в браузере посетителя, отдельно для этого пути сайта. Серверная база, реальные аккаунты, голос, внешние интеграции и отправка сообщений не подключены.

В открытый репозиторий копируются только frontend, его проверки, лицензии, дизайн-система и workflow Pages. Исходные материалы заказчика, фотографии, рабочая база, ключи, коммерческие документы, локальные отчёты и история разработки не публикуются. Серверная версия остаётся в исходном рабочем проекте.

Команда сборки в Linux/WSL:

```sh
cd frontend
npm ci --ignore-scripts --no-audit --no-fund
npm run test:drafts
npm run test:numbers
npm run test:pages
npm run build:pages
```

Результат находится в frontend/dist. Режим pages использует относительные адреса ресурсов, поэтому работает в подкаталоге /smart-assistant/. Навигация использует #. Обычный npm run build собирает исходное серверное приложение.

Текущая публикация берётся из ветки gh-pages, каталога /. В ней лежит проверенный frontend/dist и пустой файл .nojekyll. Сборка выполняется в Linux/WSL; после обновления этой ветки GitHub Pages публикует готовые файлы. Публичный URL проверяется после завершения сборки Pages.

GitHub Actions аккаунта заблокирован из-за биллинга, поэтому автоматический workflow для main не включён. Сохранён ручной workflow как альтернативный способ: после разблокировки Actions нужно выбрать GitHub Actions в настройках Pages и запустить workflow вручную. Пароли и GitHub-токены в него не добавляются.

В шапке демки указаны ограничения и кнопка сброса учебных данных. Excel - образец отчёта из исходных вымышленных данных; актуальные изменения можно выгрузить в CSV. Сброс затрагивает только данные этой демонстрации.
